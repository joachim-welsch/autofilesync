# AutoFileSync

[English](README.md) | [Deutsch](README.de.md) | [Español](README.es.md) | [Français](README.fr.md) | [Italiano](README.it.md) | [Polski](README.pl.md) | **Українська**

AutoFileSync підтримує файли у двох місцях в однаковому стані: окремий файл,
папку або ціле дерево папок. Кожне місце може бути папкою на власному
комп'ютері, мережевим диском, USB-носієм, комп'ютером, доступним через SSH,
або телефоном з Android. Налаштуйте, запустіть і забудьте.

AutoFileSync — вільне програмне забезпечення за ліцензією GNU General Public
License версії 3 або новішої; працює у Windows, macOS і Linux.

Вебсайт: <https://welsch-software.com>
Вихідний код і повідомлення про помилки: <https://github.com/joachim-welsch/autofilesync>

## Можливості

- Синхронізація файлів, папок і дерев папок з обмеженням за шаблонами.
- Порівняння за датою, розміром або вмістом; переміщення замість копіювання;
  налаштовувана обробка видалених файлів і новіших файлів у цільовому місці.
- Двостороння синхронізація, яка запам'ятовує останній стан: видалення й
  перейменування переносяться, а файли, змінені з обох боків, зберігаються як
  конфліктні копії.
- Попередній перегляд, який показує, що зробить запуск, ще до будь-яких змін.
- Нічого не губиться: покоління зберігають попередні версії, видалене
  потрапляє до кошика, від'єднаний диск ніколи не сприймається як «усе
  видалено», а масові видалення виконуються лише після підтвердження в
  попередньому перегляді.
- Джерело або ціль через SSH на NAS, сервері чи комп'ютері в домашній мережі;
  паролі зберігаються в зашифрованому вигляді.
- Телефони з Android під'єднуються за QR-кодом; шаблони зберігають фото на
  ПК, підтримують папку в однаковому стані або переносять музику на телефон.
  Застосунок (`AFS_Android/`) синхронізує у фоновому режимі, за бажанням лише
  через Wi-Fi і під час заряджання.
- Зміни застосовуються одразу: локальні папки відстежуються, а не лише
  перевіряються через фіксовані проміжки часу.
- Фонова служба, яка синхронізує з тією самою конфігурацією, навіть коли
  жоден користувач не ввійшов у систему.
- Вбудований помічник, який відповідає на запитання про програму на основі
  довідки, пояснює, чому ціль не актуальна, і пропонує відповідні команди.
- Журнал із вибором рівня, сповіщення електронною поштою про серйозні помилки
  та звіт про резервне копіювання у форматі JSON.
- Інтерфейс і довідка англійською, німецькою, іспанською, французькою,
  італійською, польською та українською мовами; мову можна вибрати в
  налаштуваннях.

## Встановлення

Готові пакети для Windows, macOS і Linux доступні на
<https://welsch-software.com>. Як зібрати програму самостійно, описано в
`doc/BUILD.md`; повне налаштування разом із фоновою службою — у
`doc/INSTALL-Linux.md` і `doc/INSTALL-macOS.md` (ці документи німецькою
мовою).

Коротко для Linux:

```bash
sudo apt install build-essential cmake git pkg-config libwxgtk3.2-dev \
                 libboost-filesystem-dev libssh-dev libssl-dev imagemagick gettext
scripts/build.sh
scripts/run_autofilesync.sh
```

## Структура

| Папка | Вміст |
|---|---|
| `AFS_Core/` | Ядро синхронізації як статична бібліотека, без інтерфейсу |
| `AFS_Desktop/` | Програма з інтерфейсом wxWidgets, довідкою та шаблонами інсталятора |
| `backgroundsync/` | Фонова служба для Linux, macOS і Windows |
| `AFS_Android/` | Застосунок для Android (Kotlin), інструкція зі збирання в `AFS_Android/README.md` |
| `po/` | Мовні каталоги |
| `third-party/` | Тексти ліцензій використаних бібліотек |

Тести: `scripts/run_Integrationtests.sh` для ядра,
`scripts/run_GUI_Tests.sh` для інтерфейсу; подробиці в `doc/BUILD.md`.
