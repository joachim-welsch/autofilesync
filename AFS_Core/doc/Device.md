# Device

Module comment for Device.h / Device.cpp.

## Device

A paired phone as the configuration keeps it: what is needed to recognise it again on the next
connection and to reach its SFTP server later. The phone chooses its id and name when it pairs
(DeviceLink.md#pair); the certificate fingerprint is taken from the TLS handshake, never from the
message, so a phone cannot register itself under another phone's certificate.

## cert_fingerprint

SHA-256 of the DER-encoded client certificate, lowercase hex. The phone's certificate is
self-signed and generated by the Android keystore, so nothing about it can be verified except
that it is the same one as at pairing time - which is exactly the check the hello needs
(DeviceLink.md#hello).

## DevicePresence

What the last contact told about a phone and when it was: address, SFTP port and app version
change between contacts, so they live in DeviceLink's memory and not in the configuration. A
configuration that changed on every hello would make the GUI ask whether to save it. The
memory is the link's run: stopping the link forgets every presence, so a restarted link shows
"not reported yet" until the phone reports in again.

## valid_device_id

32 lowercase hex digits, the format the app produces from 16 random bytes. Checked before a
device is registered and when the configuration is read, because the id names the device in
every later message and in the sync state file names of a later phase.

## serving

A phone opens its SFTP server only for a pass it asked for (DeviceLink.md#serve): the hello
brings the port, the user and a one-time password, and serving stays true until the link has
sent "done". The password lives here, in memory, for exactly that long; it is never written
anywhere, and the next hello brings a new one.

## valid_device_name

Not empty, at most 128 bytes and without control characters. The name comes from the phone
and is written to the log, the configuration and the pairing.done file, where a line break
would move the lines the other process reads as fingerprint and host key
(DeviceLink.md#shared-files).
