Global settings

Edit → Global settings… or the gear at the right of the toolbar opens the settings that apply to the whole program – not to a single synchronisation.

Language

The Language choice sets the language in which AutoFileSync shows menus, dialogs and messages. After OK the language changes at once, without a restart; it is stored in the configuration and applies at every later start, also to the background service.

With Operating system language, AutoFileSync follows the language of the operating system again. If there is no translation for it, everything appears in English. This help appears in the chosen language as well; it is available in every language the choice offers.

Start and window

Start the application automatically AutoFileSync is started along with your login.
Start synchronisation at program start Continuous operation begins right after the start, without Synchronisation → Start being needed.
Start minimised The window does not appear at start; the program goes straight into the notification area of the taskbar.
Minimise instead of closing Closing the window does not end the program but minimises it into the notification area. It is then ended with File → Quit or the context menu in the notification area.

Only one instance ever runs: a second start reports that AutoFileSync is already running and ends itself.

Showing messages in a dialog

The three ticks Error, Warning and Info set which messages appear in a dialog window in addition after Synchronise once: all messages of the run collected in one window, each with its level, at most 15 lines – the rest is in the log. Only errors are preset. Without ticks the synchronisation runs silently. Continuous operation (Start) never shows a window, because every notice would otherwise bring the window to the front; neither does a start in the minimised state.

Delete mode

The delete mode applies to every deletion AutoFileSync makes: the source with Delete the source after copying and the target with Also delete deleted files in the target.

Move to recycle bin The default. Deleted files land in the recycle bin directory given below and can be brought back from there. The original structure is kept, and files of the same name do not overwrite each other.
Delete permanently The files are removed straight away.

The Recycle bin field holds the directory for it. It should be on a drive with enough space; AutoFileSync does not clean it up by itself.

For targets over SSH, files are deleted permanently whatever this setting says, see Synchronising over SSH.
