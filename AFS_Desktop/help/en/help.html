AutoFileSync

AutoFileSync keeps files in two places up to date with each other. A place can be a directory on this machine, a network drive, a USB drive or a computer that can be reached over SSH.

Each task is set up as a synchronisation: source, target, what is compared and how special cases are handled. All synchronisations together form the configuration, which is saved as a file. They run either from within the program – once or continuously – or in a background service that uses the same configuration.

Quick start

  1. File → New synchronisation… opens the dialog for a new task.
  2. Give it a Name and choose the Type: a single file, a directory or a whole directory tree.
  3. Enter the Source and the Target, or choose them with the buttons.
  4. On the Options tab, set what files are compared by and what should happen with deletions, empty files and older versions.
  5. Confirm with OK – the configuration is saved at once – and get going with Synchronisation → Start.

The main window

The synchronisations can be shown as a List, a Tree or a Table; the choice is in the View menu. The toolbar holds the most frequent commands: edit, save, delete, start and stop; at the far right are the help and the gear for the global settings. The status bar tells what is happening right now.

When minimised, the program withdraws into the notification area of the taskbar and keeps working there.
