Running a synchronisation

The Synchronisation menu controls the run.

CommandEffect
Start Starts continuous operation. AutoFileSync works through all active synchronisations one after another, waits the pause set for each task and starts over.
Stop Ends the operation. A copy in progress is still finished, then the processing stops.
Synchronise once A single run over all active synchronisations; afterwards the processing stops by itself. See Synchronise once.

Start and the single run are only available if the configuration holds at least one synchronisation that can be run. While a run is active they are disabled.

What you see meanwhile

The right-hand field of the status bar always shows what the synchronisation is doing: Synchronisation stopped, Counting files …, Single synchronisation running …, Synchronisation running … or Paused – next run in N s when all tasks are in their pause. For longer transfers a progress dialog appears with source, target and amount. The toolbar switches between Start and Stop, so the state can be read at any time.

When the window is minimised, the synchronisation keeps running in the notification area of the taskbar.

Automatically at program start

In the global settings you can have AutoFileSync begin the synchronisation right after starting – together with Start the application automatically and Start minimised this gives a run that goes along without any action. If you want the synchronisation without the program open at all, use the background service.

Views

The View menu switches the overview:

  • List – one line per synchronisation
  • Tree – arranged by source and target
  • Table – all fields side by side, good for comparing several tasks
  • Show log file – opens the log in the configured editor, see Log and notification
  • Background – shows the state of the background service
