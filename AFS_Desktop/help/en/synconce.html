Synchronise once

Synchronisation → Synchronise once does exactly one run over all active synchronisations and stops afterwards. The pause set for the tasks plays no part in it – it applies to continuous operation only.

This is the right command to

  • try out a newly created synchronisation,
  • reconcile everything once more before unplugging a drive,
  • check the result after changing an option, without the program running on afterwards.

During the run Start and Synchronise once are disabled; afterwards they are available again. What happened is written to the log, and with the backup proof switched on also to the proof file.

If nothing should be changed and you only want to find out how much there would be to do, look into the log at log level Info: the run counts the affected files before it copies.
