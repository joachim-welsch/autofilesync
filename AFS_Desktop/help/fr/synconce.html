Synchroniser une fois

Synchronisation → Synchroniser une fois effectue exactement un passage sur toutes les synchronisations actives puis s'arrête. La pause réglée pour les tâches ne joue ici aucun rôle – elle ne vaut que pour le fonctionnement continu.

C'est la bonne commande pour

  • essayer une synchronisation nouvellement créée,
  • tout mettre en concordance une dernière fois avant de débrancher un support,
  • vérifier le résultat après avoir modifié une option, sans que le programme continue ensuite.

Pendant le passage, Démarrer et Synchroniser une fois sont désactivés ; ensuite, ils sont de nouveau disponibles. Ce qui s'est passé figure dans le journal et, si la preuve de sauvegarde est activée, aussi dans le fichier de preuve.

Si rien ne doit être modifié et que vous voulez seulement savoir combien il y aurait à faire, consultez le journal au niveau Info : le passage compte les fichiers concernés avant de copier.
