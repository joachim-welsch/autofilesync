Synchroniser avec un téléphone

AutoFileSync accorde aussi des dossiers d'un téléphone Android avec le PC : les photos arrivent d'elles-mêmes sur le PC, un dossier reste identique sur les deux appareils, ou la musique passe du PC au téléphone. Le téléphone a besoin pour cela de l'application AutoFileSync, et le téléphone et le PC doivent être sur le même Wi-Fi.

Connecter un téléphone

  1. Fichier → Connecter un téléphone… affiche un code QR. Il est valable dix minutes et pour un seul téléphone.
  2. Installez l'application sur le téléphone – depuis F-Droid ou en APK depuis welsch-software.com. Le code QR y mène également.
  3. Dans l'application, touchez Scanner le code QR, dirigez l'appareil photo vers le code et confirmez avec Connecter.
  4. L'application demande l'accès à tous les fichiers : Autoriser l'accès ouvre le réglage Android où il s'active. Sans cet accès, le PC ne peut ni lire ni écrire les dossiers du téléphone.

Le PC affiche alors « … est connecté ✓ ». Dès lors, le PC et le téléphone se reconnaissent mutuellement par leurs certificats ; un appareil étranger ne peut pas se faire passer pour l'un d'eux.

Ce qui est synchronisé

Juste après la connexion, AutoFileSync demande ce qu'il faut faire avec le téléphone. Des dossiers sur le PC et sur le téléphone sont proposés et peuvent être modifiés.

Sauvegarder photos et vidéos sur le PC Copie les photos et vidéos de DCIM/Camera sur le PC. Les photos supprimées sur le téléphone restent sur le PC – on peut ainsi libérer de la place sur le téléphone.
Garder un dossier identique sur les deux appareils Les modifications d'un côté arrivent de l'autre, suppressions et renommages compris. Si un fichier a été modifié des deux côtés, les deux versions sont conservées ; voir Synchronisation bidirectionnelle.
Musique du PC vers le téléphone Copie le dossier de musique du PC sur le téléphone. Ce qui disparaît de ce dossier est aussi retiré du téléphone.
Configurer plus tard Ne crée rien. Cela reste possible plus tard.

Chaque modèle crée une synchronisation tout à fait ordinaire. Comme toute autre, elle peut être modifiée, examinée dans l'aperçu et suivie dans le journal.

Une synchronisation personnelle avec le téléphone se crée dans le dialogue d'une synchronisation : le bouton Téléphone… à côté de SSH… choisit le téléphone et un dossier sur celui-ci. La liste nomme les dossiers habituels comme DCIM/Camera, Download ou Music ; un autre peut être saisi.

Quand la synchronisation a lieu

Un passage avec le téléphone commence quand le téléphone se signale au PC :

  • toutes les 30 minutes,
  • une minute après de nouvelles photos ou vidéos,
  • immédiatement avec Synchroniser maintenant dans l'application.

Deux interrupteurs dans l'application décident quand le téléphone se signale : Uniquement en Wi-Fi (activé au départ) et Uniquement pendant la charge (désactivé au départ). Sous 15 % de batterie, le téléphone attend d'être branché au chargeur. Pendant un passage, le téléphone affiche la progression dans une notification.

Un téléphone absent n'est pas une erreur : AutoFileSync attend simplement qu'il se signale de nouveau. Si le téléphone n'atteint pas le PC pendant toute une journée, il le rappelle une fois par une notification.

Si le PC obtient une nouvelle adresse dans le réseau domestique, le téléphone le retrouve de lui-même. Si le service en arrière-plan tourne, il accepte les téléphones même quand personne n'est connecté au PC.

Les fichiers du téléphone ne sont accessibles au PC que pendant un passage, et seulement avec un mot de passe généré à nouveau pour chaque passage.

Téléphones connectés

Édition → Téléphones… liste tous les téléphones connectés.

  • Un clic sur le nom renomme le téléphone.
  • Configurer la synchronisation… rouvre les modèles.
  • Déconnecter retire le téléphone. Il ne peut plus se signaler ; pour le connecter à nouveau, scannez un nouveau code. Dans l'application, Se déconnecter du PC coupe la connexion de l'autre côté.

Pare-feu

Le téléphone joint le PC par le port 52381. Un pare-feu sur le PC doit ouvrir ce port pour TCP et UDP. Sous Linux avec ufw, ceci suffit :

sudo ufw allow 52381

Si rien n'arrive dans la minute pendant la connexion, le dialogue signale lui-même le pare-feu.

Si cela ne fonctionne pas

  • L'application indique « PC injoignable ». Le PC est-il allumé et sur le même Wi-Fi que le téléphone ? Un Wi-Fi invité ou un Wi-Fi qui isole les appareils les uns des autres ne permet pas de connexion.
  • Le téléphone dit que le PC a refusé le code ou n'attend pas. Un code ne vaut que tant que le dialogue est ouvert, et pendant dix minutes. Rouvrez Fichier → Connecter un téléphone… et scannez le nouveau code.
  • Le dialogue attend sans fin. Le pare-feu bloque probablement (voir plus haut).
  • Rien n'est transféré. L'application a-t-elle accès à tous les fichiers ? « Uniquement en Wi-Fi » ou « Uniquement pendant la charge » est-il activé alors que le téléphone est absent ou ne charge pas ?
