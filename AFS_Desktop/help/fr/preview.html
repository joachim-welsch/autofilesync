Aperçu

Synchronisation → Aperçu… montre ce qu'un passage ferait maintenant sans rien modifier : rien n'est copié, déplacé ni supprimé. Ce n'est que lorsque vous choisissez Synchroniser maintenant dans la boîte de dialogue que la synchronisation s'exécute – exactement comme si vous aviez choisi Synchroniser une fois.

L'aperçu est surtout utile

  • après la création d'une nouvelle synchronisation, pour vérifier que source et cible ne sont pas inversées,
  • avant d'activer pour la première fois Supprimer dans la cible les fichiers supprimés ou Supprimer la source après la copie,
  • quand vous voulez savoir combien un passage transférerait.

La boîte de dialogue

Chaque ligne est une étape que le passage exécuterait :

ActionSignification
Copier vers la cible Le fichier est nouveau ou plus récent dans la source que dans la cible.
Déplacer vers la cible Comme la copie ; ensuite le fichier source est retiré, parce que Supprimer la source après la copie est activé.
Recopier vers la source Avec la synchronisation bidirectionnelle : le fichier n'existe que dans la cible ou y est plus récent.
Supprimer dans la cible Le fichier n'existe plus dans la source et Supprimer dans la cible les fichiers supprimés est activé, ou la synchronisation bidirectionnelle a reconnu qu'il a été supprimé dans la source. Ces lignes sont en rouge parce qu'elles retirent des données.
Supprimer dans la source Avec la synchronisation bidirectionnelle : le fichier a été supprimé dans la cible depuis sa dernière synchronisation. Ces lignes sont en rouge elles aussi.
Renommer dans la cible, Renommer dans la source Le fichier a été renommé ou déplacé de l'autre côté ; ici il est seulement renommé, rien n'est transféré. La colonne Fichier montre l'ancien et le nouveau nom.
Créer une copie de conflit, la source l'emporte, …, la cible l'emporte Le fichier a été modifié des deux côtés depuis la dernière synchronisation. Le côté nommé est copié de l'autre ; la version précédente de celui-ci survit comme copie de conflit et arrive elle aussi des deux côtés.

Sous la liste figure le résumé : combien d'étapes, combien d'entre elles sont des suppressions et quel volume de données serait transféré. Les messages de la vérification – une source inaccessible, par exemple – apparaissent sous la liste. Si un très grand nombre d'étapes est prévu, la liste montre les dix mille premières et indique le nombre des autres.

Si la source et la cible concordent, seule une note indiquant qu'un passage ne ferait rien apparaît à la place de la boîte de dialogue.

Ce que l'aperçu ne prend pas en compte

  • La pause d'une synchronisation ne joue aucun rôle : l'aperçu montre la différence entre la source et la cible, même juste après un passage.
  • Ce qui change encore entre l'aperçu et le passage n'est vu que par le passage.
  • Les erreurs lors de la copie elle-même – une cible pleine, par exemple – ne se manifestent que pendant le passage et figurent alors dans le journal.
