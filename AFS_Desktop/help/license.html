Lizenzdatei

Beim Start zeigt die Statuszeile fünf Sekunden lang, für wen AutoFileSync lizenziert ist: Lizenziert für und den Namen des Lizenznehmers. Ohne Lizenzdatei steht dort Lizenziert für private Nutzung. Die Lizenz ändert nichts am Funktionsumfang – sie benennt nur den Lizenznehmer.

Die Lizenzdatei weist eine kommerzielle Lizenz nach; ohne sie gilt die GPL.

Wo sie liegt

Die Datei heißt autofilesync.lic. AutoFileSync sucht sie zuerst im Verzeichnis der Konfigurationsdatei, dann im Verzeichnis des Programms:

Windows %APPDATA%\autofilesync\autofilesync.lic, ersatzweise neben autofilesync.exe
Linux $XDG_CONFIG_HOME/autofilesync/autofilesync.lic, ersatzweise ~/.config/autofilesync/autofilesync.lic oder neben dem Programm
macOS ~/Library/Application Support/autofilesync/autofilesync.lic, ersatzweise neben dem Programm

Die erste gefundene Datei zählt. So lässt sich eine Installation auch dann lizenzieren, wenn das Programmverzeichnis nicht beschreibbar ist.

Wie sie aussieht

Eine Textdatei mit dem Namen des Lizenznehmers und einer Signatur:

Licensee: Firma Beispiel GmbH
Signature: 75921b43c5513d14a8235f3189817bcea1b9608682df49e726e81b6d9a290d17…

Die Signatur (Ed25519) sichert den Text davor ab. Sie wird vom Hersteller mit einem geheimen Schlüssel erzeugt; das Programm prüft sie mit dem eingebauten öffentlichen Gegenstück. Eine Datei, deren Text verändert wurde oder deren Signatur nicht passt, wird nicht verwendet – AutoFileSync verhält sich dann wie ohne Lizenzdatei und schreibt eine Warnung mit dem Pfad ins Protokoll.

Die Datei darf mit einem Editor angesehen werden; auch wenn der Editor die Zeilenenden ändert, bleibt die Signatur gültig. Nur der Text der Zeilen darf sich nicht ändern.

Private Nutzung

Eine Lizenz ohne Lizenznehmer – die Zeile Licensee: bleibt leer, die Signatur ist vorhanden – gilt als Lizenz für private Nutzung. Die Statuszeile zeigt dann dasselbe wie ohne Datei: Lizenziert für private Nutzung.
