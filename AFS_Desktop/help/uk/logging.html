Журнал і сповіщення

Редагування → Параметри журналу… визначає, що записується і як ви дізнаєтеся про серйозні помилки.

Журнал

Шлях до файлу журналу Розташування файлу журналу. Без власного шляху AutoFileSync записує в Windows до %LOCALAPPDATA%\autofilesync\autofilesync.log, у Linux – до ~/.cache/autofilesync/autofilesync.log. Папка створюється за потреби.
Рівень журналу З якого рівня записуються повідомлення: Debug, Info, Warning, Error або FatalError. Debug записує кожен крок і швидко збільшує файл – він призначений для пошуку несправностей, а не для постійної роботи. Info фіксує, що було скопійовано й видалено.
Історія [днів] Як довго зберігаються записи. Під час запуску програми старіші рядки видаляються, новіші залишаються.
Редактор Програма, якою Вигляд → Показати журнал відкриває журнал.
Шлях для підтверджень резервного копіювання Папка для файлів підтвердження, див. Підтвердження резервного копіювання.

Сповіщення електронною поштою

На другій вкладці можна налаштувати сповіщення, яке надсилає лист у разі серйозної помилки – корисно, коли AutoFileSync працює без нагляду або як фонова служба.

Активна Вмикає надсилання. Без позначки решта налаштувань не діє.
Адреса ел. пошти Одержувач сповіщення.
Сервер вихідної пошти, Порт Сервер SMTP і порт постачальника.
Користувач, Пароль Дані для входу на сервер вихідної пошти.
Відправник Адреса, яка вказується як відправник. Багато постачальників вимагають, щоб вона належала до облікового запису.

Якщо при ввімкненому сповіщенні бракує одержувача, сервера або відправника, діалог укаже на це під час підтвердження. Та сама помилка не надсилає лист скільки завгодно разів – після одного повідомлення вона деякий час мовчить, щоб призначення, яке тривалий час недоступне, не переповнило поштову скриньку.
