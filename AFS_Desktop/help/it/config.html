File di configurazione

Tutte le sincronizzazioni, le connessioni SSH e le impostazioni sono in un unico file in formato JSON. È questo il file che il programma e il servizio in background usano insieme.

Dove si trova

Windows %APPDATA%\autofilesync\autofilesync.json
Linux $XDG_CONFIG_HOME/autofilesync/autofilesync.json, in mancanza ~/.config/autofilesync/autofilesync.json
macOS ~/Library/Application Support/autofilesync/autofilesync.json

Aprire e salvare

  • File → Apri… carica un'altra configurazione, per esempio un insieme di sincronizzazioni per uno scopo preciso.
  • Ogni modifica viene salvata subito – una spunta nella tabella come una finestra chiusa con OK. Non serve un salvataggio a parte.
  • File → Salva si può scegliere solo se la scrittura automatica non è riuscita, per esempio con il disco pieno. In quel caso il titolo della finestra mostra (non salvato), e il programma chiede prima di uscire e prima di avviare il servizio in background.
  • File → Salva con nome… crea una copia. Se il file esiste già, viene chiesta conferma prima di sovrascriverlo.

Che cosa contiene

Per ogni sincronizzazione nome, tipo, origine, destinazione, carattere jolly, esclusioni, le opzioni e la pausa; inoltre le connessioni SSH e le impostazioni generali. Le password delle connessioni SSH e del server di posta in uscita sono salvate cifrate, non in chiaro.

Il file è in UTF-8 e in caso di necessità si può guardare con un editor di testo. Una chiave che una versione precedente del programma non conosceva manca semplicemente nei file vecchi – AutoFileSync usa allora il valore predefinito documentato e carica comunque il file. Nemmeno una singola voce danneggiata fa perdere l'intera configurazione; viene saltata.

Durante la scrittura il file esistente non viene distrutto se il salvataggio non riesce – nel dubbio resta lo stato precedente.
