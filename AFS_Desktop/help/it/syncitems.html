Creare sincronizzazioni

Una sincronizzazione descrive un compito: che cosa viene allineato, da dove e verso dove. Si crea con File → Nuova sincronizzazione… e si modifica con Modifica → Modifica sincronizzazione… oppure con un doppio clic sulla voce.

Nome

Il nome identifica la sincronizzazione e deve essere univoco. Compare nell'elenco, nel log e – se attivata – come nome del file della prova di backup.

Tipo

TipoChe cosa viene allineato
File Esattamente un file. Origine e destinazione sono nomi di file completi.
Cartella Tutti i file di una cartella, senza le sue sottocartelle.
Albero di cartelle Una cartella con tutte le sottocartelle. Le cartelle di destinazione mancanti vengono create.

Origine e destinazione

Entrambi i campi accettano un percorso. Il pulsante accanto apre la scelta; per un computer all'altro capo di una connessione SSH c'è un pulsante apposito, vedere Sincronizzare tramite SSH.

Accanto alla destinazione c'è inoltre «Cloud…». Il pulsante mostra le cartelle che i programmi di OneDrive, Google Drive, Dropbox, Nextcloud o iCloud hanno creato su questo computer e apre la scelta all'interno di quella selezionata. Ciò che AutoFileSync vi copia viene caricato nel cloud dal programma del fornitore, che deve essere installato e avere l'accesso effettuato.

Una destinazione che non esiste ancora viene creata alla prima esecuzione. Se l'origine si trova su un'unità rimovibile o su un'unità di rete al momento non collegata, AutoFileSync salta la sincronizzazione e non tocca la destinazione – è importante, perché un'unità scollegata non venga scambiata per «è stato eliminato tutto».

Carattere jolly

Per i tipi Cartella e Albero di cartelle, il campo Carattere jolly limita quali file vengono presi in considerazione, per esempio *.txt per i file di testo o *.* per tutti. I file che non corrispondono sono invisibili per questa sincronizzazione: non vengono né copiati né eliminati, nemmeno quando i file eliminati vanno eliminati anche nella destinazione.

Esclusioni

Nella scheda Esclusioni si scrive un modello per riga, per esempio:

*.tmp
node_modules
Thumbs.db

Le esclusioni valgono sia per la copia sia per l'eliminazione. In un albero di cartelle, una cartella esclusa non viene nemmeno aperta – si risparmia tempo e non serve controllare uno per uno i file che contiene.

Attiva

Una sincronizzazione senza la spunta Sincronizzazione attiva resta nell'elenco, ma non viene eseguita. Così si può mettere da parte un compito per un po' senza perderlo.
