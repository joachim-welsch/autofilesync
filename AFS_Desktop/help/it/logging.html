Log e notifiche

Modifica → Impostazioni di registrazione… stabilisce che cosa viene registrato e come si viene informati degli errori gravi.

Log

Percorso del file di log Posizione del file di log. Senza un percorso proprio AutoFileSync scrive su Windows in %LOCALAPPDATA%\autofilesync\autofilesync.log, su Linux in ~/.cache/autofilesync/autofilesync.log. La cartella viene creata quando serve.
Livello di log Da quale livello in poi si scrive: Debug, Info, Warning, Error o FatalError. Debug registra ogni passo e fa crescere il file rapidamente – serve per cercare problemi, non per l'uso continuo. Info registra che cosa è stato copiato ed eliminato.
Cronologia [giorni] Per quanto tempo vengono conservate le voci. All'avvio del programma le righe più vecchie vengono rimosse, quelle più recenti restano.
Editor Programma con cui Visualizza → Mostra file di log apre il log.
Percorso per le prove di backup Cartella per i file di prova, vedere Prova di backup.

Notifica via e-mail

Nella seconda scheda si può impostare una notifica che, in caso di errore grave, invia un'e-mail – utile quando AutoFileSync lavora senza sorveglianza o come servizio in background.

Attiva Attiva l'invio. Senza spunta tutto il resto non ha effetto.
Indirizzo e-mail Destinatario della notifica.
Server di posta in uscita, Porta Server SMTP e porta del fornitore.
Utente, Password Dati di accesso per il server di posta in uscita.
Mittente Indirizzo inserito come mittente. Molti fornitori richiedono che appartenga all'account.

Se con la notifica attiva mancano destinatario, server o mittente, la finestra lo segnala alla conferma. Lo stesso errore non invia e-mail all'infinito – dopo una segnalazione resta in silenzio per un po', così una destinazione irraggiungibile a lungo non riempie la casella di posta.
