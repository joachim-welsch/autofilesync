Registro y notificación

Edición → Configuración del registro… controla qué se anota y cómo se entera usted de los errores graves.

Registro

Ruta del archivo de registro Ubicación del archivo de registro. Sin una ruta propia, AutoFileSync escribe en %LOCALAPPDATA%\autofilesync\autofilesync.log en Windows y en ~/.cache/autofilesync/autofilesync.log en Linux. La carpeta se crea cuando hace falta.
Nivel de registro A partir de qué nivel se escribe: Debug, Info, Warning, Error o FatalError. Debug anota cada paso y hace crecer el archivo deprisa – pensado para buscar errores, no para el funcionamiento continuo. Info anota qué se copió y qué se eliminó.
Historial [días] Cuánto tiempo se conservan las entradas. Al iniciar el programa se eliminan las líneas más antiguas; las más recientes se quedan.
Editor Programa con el que Ver → Mostrar archivo de registro abre el registro.
Ruta de los comprobantes de copia Carpeta para los archivos de comprobante; consulte Comprobante de copia.

Notificación por correo electrónico

En la segunda pestaña puede configurar una notificación que envía un correo electrónico ante un error grave – útil cuando AutoFileSync funciona sin supervisión o como servicio en segundo plano.

Activa Activa el envío. Sin la marca, todo lo demás no tiene efecto.
Dirección de correo Destinatario de la notificación.
Servidor de correo saliente, Puerto Servidor SMTP y puerto del proveedor.
Usuario, Contraseña Datos de acceso al servidor de correo saliente.
Remitente Dirección que figura como remitente. Muchos proveedores exigen que pertenezca a la cuenta.

Si con la notificación activa faltan el destinatario, el servidor o el remitente, el diálogo lo indica al confirmar. El mismo error no envía un correo una y otra vez – tras un aviso queda en silencio durante un tiempo, para que un destino inaccesible durante mucho tiempo no llene el buzón.
