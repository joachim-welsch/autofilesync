Archivo de configuración

Todas las sincronizaciones, conexiones SSH y opciones están en un archivo en formato JSON. Es el archivo que comparten el programa y el servicio en segundo plano.

Dónde está

Windows %APPDATA%\autofilesync\autofilesync.json
Linux $XDG_CONFIG_HOME/autofilesync/autofilesync.json; si no, ~/.config/autofilesync/autofilesync.json
macOS ~/Library/Application Support/autofilesync/autofilesync.json

Abrir y guardar

  • Archivo → Abrir… carga otra configuración, por ejemplo un conjunto de sincronizaciones para un fin determinado.
  • Cada cambio se guarda al instante – una marca en la tabla igual que un diálogo cerrado con OK. No hace falta un paso de guardado aparte.
  • Archivo → Guardar solo se puede elegir si la escritura automática ha fallado, por ejemplo con el disco lleno. Mientras tanto el título de la ventana muestra (sin guardar), y el programa pregunta antes de salir y antes de iniciar el servicio en segundo plano.
  • Archivo → Guardar como… crea una copia. Si el archivo ya existe, se pregunta antes de sobrescribirlo.

Qué contiene

Para cada sincronización: nombre, tipo, origen, destino, comodín, exclusiones, las opciones y la pausa; además, las conexiones SSH y la configuración general. Las contraseñas de las conexiones SSH y del servidor de correo saliente se guardan cifradas, no en texto claro.

El archivo está en UTF-8 y, en caso de necesidad, se puede consultar con un editor de texto. Una clave que una versión anterior del programa aún no conocía simplemente falta en los archivos antiguos – AutoFileSync usa entonces el valor predeterminado documentado y carga el archivo igualmente. Una sola entrada dañada tampoco hace que se pierda toda la configuración; se omite.

Al escribir, el archivo existente no se destruye si falla el guardado – en caso de duda se conserva el estado anterior.
