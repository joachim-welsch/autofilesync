Konfigurationsdatei

Alle Synchronisationen, SSH-Verbindungen und Einstellungen stehen in einer Datei im JSON-Format. Sie ist es, die das Programm und der Hintergrunddienst gemeinsam benutzen.

Wo sie liegt

Windows %APPDATA%\autofilesync\autofilesync.json
Linux $XDG_CONFIG_HOME/autofilesync/autofilesync.json, ersatzweise ~/.config/autofilesync/autofilesync.json
macOS ~/Library/Application Support/autofilesync/autofilesync.json

Öffnen und Speichern

  • Datei → Öffnen lädt eine andere Konfiguration, etwa einen Satz Synchronisationen für einen bestimmten Zweck.
  • Datei → Speichern schreibt die Änderungen zurück. Ohne Speichern gehen sie beim Beenden verloren.
  • Datei → Speichern als legt eine Kopie an. Existiert die Datei bereits, wird vor dem Überschreiben gefragt.

Was drin steht

Je Synchronisation Name, Typ, Quelle, Ziel, Platzhalter, Ausschlüsse, die Optionen und die Pause; dazu die SSH-Verbindungen und die globalen Einstellungen. Passwörter für SSH-Verbindungen und für den Postausgangsserver werden verschlüsselt abgelegt, nicht im Klartext.

Die Datei lässt sich im Notfall mit einem Texteditor betrachten. Ein Schlüssel, den eine ältere Ausgabe des Programms noch nicht kannte, fehlt in alten Dateien einfach – AutoFileSync setzt dann die dokumentierte Vorgabe ein und lädt die Datei trotzdem. Ein einzelner beschädigter Eintrag führt ebenfalls nicht dazu, dass die ganze Konfiguration verloren geht; er wird übersprungen.

Beim Schreiben wird die vorhandene Datei nicht zerstört, falls das Speichern scheitert – im Zweifel bleibt der alte Stand erhalten.
